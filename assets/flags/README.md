# Flag artwork

The 14 SVG files are unmodified 4:3 flags from flag-icons v7.5.0:
https://github.com/lipis/flag-icons/tree/v7.5.0/flags/4x3

Copyright (c) 2013 Panayiotis Lipiridis. See LICENSE for the upstream MIT license.
Flags are bundled locally, with no network requests at runtime. The language-to-flag
mapping is in src/shared/appearance.ts; Traditional Chinese uses Hong Kong (hk),
and Simplified Chinese uses China (cn).
