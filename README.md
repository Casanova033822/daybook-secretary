# 日序 · Windows 私人秘書

個人使用的離線桌面行程與提醒工具。所有資料留在本機，不需帳號或雲端服務。

## 安裝與使用

支援 Windows x64；目前實測 Windows 11 x64。請到本 GitHub 儲存庫的 **Releases** 下載 `Daybook-Setup-1.0.5.exe`，安裝後從桌面或開始功能表開啟「日序」。使用安裝版**不需要 Node.js、npm 或另裝字體**；覆蓋更新會沿用原本的行程與設定。

GitHub 的 **Code → Download ZIP** 是原始碼，需依下方開發步驟建置，不含安裝程式。尚未發佈 Release 時須自行建置。本版未做程式碼簽章，Windows 可能顯示未識別發行者或 SmartScreen 警告；可用 Release 附的 `SHA256SUMS.txt` 核對檔案完整性。雜湊不能代替簽章或證明發行者身分。不提供 macOS、Linux 或原生 Windows ARM64 安裝包。

- **新增事項**：可輸入名稱，也可按欄位右側箭頭選擇常用事項。
- **設定時間**：小時下拉為 00～24；分鐘下拉為 00、05、10…55。手動分鐘可輸入 00～59，例如 09:07。24:00 代表所選日期的隔天 00:00。
- **先記成待辦**：沒有決定時段時，只需填日期與名稱；之後可編輯改成行程。
- **提早完成**：點事項左側的方框，立刻打勾並加上刪除線，取消該次後續提醒。再點一次可取消完成，只恢復未來提醒。
- **直接刪除**：完整時間表與待辦每列右側依序為編輯、垃圾桶。點垃圾桶只刪除所選的那一次，不跳出選擇或確認視窗；固定行程的其他日期保留。編輯視窗內的垃圾桶也只刪除當次。
- **固定行程**：每天或每週指定星期重複，可選截止日期。編輯時可選「僅本次」或「本次及未來」。完成與刪除只影響單次。
- **常用事項**：在「偏好設定 → 常用事項」新增、改名、刪除、上下排序，再按「儲存常用事項」。不會更改已建立的行程。
- **迷你模式**：標題列的迷你視窗按鈕可切換；可以拖曳、縮放、勾選完成。圖釘按鈕切換保持最上層。
- **背景提醒**：關閉視窗會收進系統匣，仍會提醒。右鍵系統匣的日序圖示可切換模式或完全結束。
- **登入啟動**：安裝版本預設於登入 Windows 後在背景執行，可在偏好設定關閉。開發版本不註冊登入啟動。
- **測試提醒**：偏好設定的一般設定頁提供測試按鈕，與正式提醒使用同一流程。在滑鼠所在螢幕的右下角顯示日序小卡，10 秒後自動關閉，點擊可開啟行程；不搶鍵盤焦點。
- **提示音**：由獨立提醒視窗播放程式附帶的短提示音，同批提醒合併顯示並播放一次。音量與靜音仍依電腦設定；不依賴 Windows 通知橫幅與通知音效。
- **清晰時間表**：使用本機 Noto Sans TC，沒有此字體時使用微軟正黑體。起訖時間同列顯示，跨日另外標示結束日期；狀態與提醒分欄。

睡眠及關機期間不會喚醒電腦。開啟或喚醒後，當天尚未完成事項的漏掉提醒會合併成一則摘要，過往日期不補發。

## 資料與規則

- 資料預設位於 `%APPDATA%\日序\daybook.sqlite`；視窗位置、常用事項與提醒紀錄一併儲存。
- 資料庫未加密，同一 Windows 帳號或系統管理員可以讀取；程式不收集遙測，也不提供雲端同步。回報問題請勿附上個人資料庫或未遮蔽的行程截圖。
- 儲存採 SQLite 交易；介面只在儲存成功後更新。完整、迷你、日、週、月檢視共用同一份資料。
- 行程開始至結束前、且未完成時標示進行中。首尾相接不算重疊；時段衝突不阻擋儲存。
- 未排時間的待辦不發提醒；改期與刪除會使舊排程失效。新建立或改動的提醒不會補發已過去的時點。
- 小卡成功顯示後才寫入已提醒紀錄。顯示失敗會在約 2 秒、5 秒後重試，最多 3 次；音效失敗另記錄，不重複顯示已成功的小卡。啟動時可再補發當日尚未成功的提醒，既有已提醒紀錄不會重播。
- 若已顯示的小卡無法寫入提醒紀錄，程式會保留本次執行的去重狀態，重試儲存而不再次彈卡。若紀錄尚未成功寫入就結束程式或斷電，重新啟動後仍可能補發。
- 修改「本次及未來」會建立新的後續規則，保留此前的行程；未來原有的個別改期會被這次批次設定取代，符合新規則日期的完成狀態保留。
- 使用本地日期時間，重複行程維持當地鐘面時間；系統時間調整及喚醒後重新檢查。不存在的日光節約時間會在輸入時拒絕。
- 沒有倒數、稍後提醒、帳號、資料同步或歷史統計。不自動刪除過期事項。

## 開發

需要 Windows x64、Node.js **24.x**（包含 npm）與網際網路以安裝建置依賴。依賴版本記錄於 `package-lock.json`，請使用 `npm ci`。無須手動安裝 SQLite、Python 或 Visual Studio C++ 工具。應用程式本身離線可用。

```powershell
npm ci
npm run dev
```

建置後啟動：

```powershell
npm run build
npm start
```

產生安裝程式：

```powershell
npm run dist
npm run test:release
```

輸出為 `release/Daybook-Setup-1.0.5.exe` 和 `release/SHA256SUMS.txt`。打包會產生第三方授權清單、檢查包內檔案及 Electron 安全開關。首次打包需下載 Electron 和 NSIS；亦提供 GitHub Actions Windows 建置工作流程。

採用 Electron、React、TypeScript、Vite、FullCalendar 標準版與 Node 內建 SQLite。主程序負責資料及提醒，sandboxed renderer 僅能呼叫 preload 白名單中的具型別介面；正式版只載入內附頁面、阻擋外部網路請求，不提供外部 HTTP API。詳見 [SECURITY.md](SECURITY.md)。

主要程式位置：`src/` 為介面、`src/shared/` 為共用時間及行程邏輯、`electron/` 為 Windows 整合與資料儲存。

## 驗證

```powershell
npm run typecheck
npm test
npm run build
npm run test:desktop
```

邏輯測試使用獨立 SQLite 資料庫，涵蓋分鐘輸入、跨日、重複行程、單次／未來修改、提早完成、非同步投遞、重試、去重與喚醒補發。桌面測試使用隔離資料夾；會顯示真正的提醒小卡與播放音效，不影響個人行程。畫面截圖輸出至 `test-results/`。

`node tests/layout.mjs` 檢查字體備援與兩種寬度的對齊。`node tests/delete-row.mjs` 檢查直接刪除當次與失敗保留資料。`node tests/reminders.mjs` 使用接下來三個整分鐘的行程，驗證完整／迷你／背景模式、合併提醒、完成與改期、顯示失敗重試、重新啟動及模擬喚醒；執行約 3 分鐘。這些測試針對開發版，需要 Windows 桌面工作階段。

`node tests/editor-review.mjs` 驗證不同事項的編輯草稿隔離、儲存競態及自訂提醒輸入；`node tests/window-storage.mjs` 模擬視窗偏好儲存失敗，驗證仍可操作視窗。

打包版本請使用 `npm run test:release`，亦可執行 `node tests/release.mjs "安裝後的日序.exe路徑"`。測試使用獨立資料目錄，不註冊登入啟動，會顯示小卡與播放音效。正式版已關閉 Node 偵錯介面，舊的 `tests/windows.mjs` 及 Playwright Electron 主程序偵錯測試不能直接套用正式版。

人工驗收包含：喇叭實際可聽見提示音、登入自動執行、真實睡眠／喚醒、多螢幕拔除後位置。播放完成回呼不等同使用者實際聽見。詳見 [VERIFICATION.md](VERIFICATION.md)；發佈步驟見 [RELEASING.md](RELEASING.md)。
